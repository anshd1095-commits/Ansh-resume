## Free hosting with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new **public** repository, e.g. `ansh-resume`.
3. Upload all three files to the repository root.
4. Open **Settings → Pages**.
5. Under "Build and deployment", choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.
7. GitHub will give you a free website link such as:
   `https://YOUR-USERNAME.github.io/ansh-resume/`
